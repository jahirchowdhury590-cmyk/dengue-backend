# 🦟 AegisDengue AI - Outbreak Risk Predictor

A modern, full-stack Machine Learning web application that predicts the risk of Dengue outbreaks in various cities based on real-time climate data.

## 🚀 Live Links
- **Frontend Dashboard:** [https://dengue-watch-alert.lovable.app](https://dengue-watch-alert.lovable.app)
- **Backend API:** `https://dengue-backend-hjz1.onrender.com`

## 🛠️ Tech Stack
- **Frontend:** React, Lovable, Tailwind CSS
- **Backend:** Python, FastAPI, Uvicorn
- **Machine Learning:** Scikit-Learn
- **External Data:** OpenWeatherMap API

## 📌 Features
- Real-time weather data fetching (Temperature, Humidity, Rainfall).
- Machine Learning model predicts expected dengue cases.
- Dynamic Risk Alerts (Low, Medium, High) with health advisories.
